# Jibran Ali Portfolio

Personal portfolio site for Jibran Ali, senior full-stack engineer.

It is a static site: one `index.html` plus `Jibran_Ali_CV.pdf`, with no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Deploy

Import this repository in Vercel with the framework preset set to "Other" and no build command. Every push to `main` redeploys.
