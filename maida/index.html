Moving a live product from Rails to Next.js and NestJS

NextAgency, as lead engineer

The platform had outgrown its server-rendered Rails views. I led the move to a Next.js front end and a NestJS API while the existing product stayed live.

  • Set the front-end architecture: Next.js App Router, TypeScript, server-side rendering for data-heavy pages
  • Moved Rails features and APIs into NestJS services with JWT authentication
  • Built the new pages straight from designers' Figma files, with Tailwind CSS

Built with Next.js, React, TypeScript, NestJS, Node.js, Tailwind CSS

Making slow pages fast

NextAgency, performance

I traced a slow page to a single PostgreSQL query and cut it from 4,200 ms to 28 ms with the right indexes, then made the database ready for growth.

  • Added an RDS read replica to spread read load off the primary database
  • Caching with Redis (Sidekiq, AWS ElastiCache) and search with Elasticsearch
  • Lazy loading and CloudFront CDN on the front end

Built with PostgreSQL, Redis, Elasticsearch, AWS RDS, CloudFront
