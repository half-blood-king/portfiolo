Moving a live product from Rails to Next.js and NestJS

The platform had outgrown its server-rendered Rails views. I led the move to a Next.js front end and a NestJS API while the existing product stayed live.

  • Set the front-end architecture: Next.js App Router, TypeScript, server-side rendering for data-heavy pages
  • Moved Rails features and APIs into NestJS services with JWT authentication
  • Built the new pages straight from designers' Figma files, with Tailwind CSS
